# Data Jobs Dashboard using Power BI

![Dashboard Page 1](/images/project_page_1.png)

## Introduction
This dashboard was created to provide data‑focused job seekers with clear, actionable insights into the current job market. Using a real‑world dataset of 2024 data science job postings (including titles, salaries, locations, and more) it enables users to compare major roles in the data domain, such as Data Analyst and Data Scientist, while also offering detailed, role‑specific breakdowns for deeper exploration.

## Skills Showcased
This project provided a hands‑on opportunity to work with a wide range of Power BI capabilities. Throughout the development process, I applied and refined several core skills, including:

⚙️ **Data Preparation (ETL) with Power Query**  
Cleaned and transformed the raw dataset by addressing
- missing values
- adjusting data types
- and creating additional calculated columns to support analysis.

🧮 **Custom Measures**  
Built measures to surface key insights and metrics such as median salary figures and total job counts.

📊 **Visualization Techniques**  
Used a variety of chart types (including column, bar, line, and area charts) to highlight trends and compare job‑related metrics.

🗺️ **Geographic Insights**  
Incorporated map visuals to display the distribution of job postings across different regions.

🔢 **KPI & Tabular Elements**  
Added card visuals for quick, high‑level indicators and tables for detailed, sortable information.

🎨 **Report Layout & Design**  
Focused on creating a clean, intuitive dashboard layout, experimenting with different visual styles to best communicate the data story.

🖱️ **Interactive Features**
- Slicers: for filtering by job title and other attributes
- Buttons and bookmarks: to enable smooth navigation between report pages
- Drill‑through functionality: to move from summary views to detailed role‑specific insights

## Dashboard Overview
The report consists of two complementary pages, offering both a broad market overview and a focused, role‑specific analysis.

### Page 1: Data Job Market Overview

![Dashboard Page 1](/images/project_page_1.png)

This page serves as a high‑level snapshot of the data job landscape. It highlights essential KPIs such as the total job count or median salaries to help users quickly understand overall trends at a glance.

### Page 2: Role‑Specific Drill‑Through

![Dashboard Page 1](/images/project_page_2.png)

This page provides a deeper, more detailed look at an individual job title. From the main dashboard, users can drill through to explore metrics such as remote‑work availability, leading hiring platforms, and a map showing role specific global job counts.

## Conclusion

This dashboard demonstrates how Power BI can turn raw job‑posting data into a meaningful, data‑driven resource for career analysis. Through interactive filtering, slicing, and drill‑through capabilities, users can navigate the data with ease and gain a clearer understanding of the roles, trends, and opportunities.
